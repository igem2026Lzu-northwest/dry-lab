# iGEM Dry Lab: Space Radiation Intestinal Protection System

Welcome to the Dry Lab repository for our iGEM project!

**Project Title:** A Synthetic Biology-Based Intestinal Protection System for Space Radiation.

## 📖 Project Overview

In deep-space missions and future Mars habitation, astronauts face long-term exposure to space radiation. The intestine is highly radiosensitive, leading to barrier damage, microbiota imbalance, and inflammation. Our project aims to build an engineered probiotic system that secretes **melanin** (to scavenge ROS) and **lactate** (to support epithelial repair and modulate gut microbiota).

This repository contains all the computational models, scripts, and data generated by the Dry Lab team to support this engineering strategy.

## 🧩 Module Architecture

The Dry Lab work is divided into four distinct modules:

1. **FLUKA Simulation (Collaborator)**: Monte Carlo radiation transport modeling to evaluate the physical shielding effect of melanin. (Not included in this repository).
2. **Lactate Production (干实验乳酸生产)**: Using genome-scale metabolic models (GEMs, `iJO1366star`) to predict optimal gene knockouts and two-stage fermentation strategies for maximizing lactate yield.
3. **Tyrosine Pathway (酪氨酸通路)**: Introducing a melanin synthesis pathway into *E. coli* and exploring metabolic engineering strategies to increase tyrosine supply.
4. **Gut Microbiome GEM (菌群GEM)**: Building an 11-species community model (Monod ODE & SteadyCom) using 16S rRNA data from irradiated mice to predict how lactate regulates the gut microbiota.

🚀 Key Workflows & Scripts
1. Lactate Production
Core Model: iJO1366star extended with a melanin synthesis pathway.
Key Parameters: Glucose uptake = -8 mmol/gDCW/h, ATPM = 8.39, Strict anaerobic, and CO2 exchange disabled to prevent dark carbon fixation.
Core Scripts: We bypass the standard RAVEN solveLP to avoid getCurrentTask dependency issues, directly calling the Gurobi low-level API (gurobi()) for LP solving. The model faithfully reproduces the mixed-acid fermentation profile of WT E. coli.
Two-stage Yield: Note that the apparent yield in Stage 2 (2.17 mol/mol glucose) slightly exceeds the theoretical limit (2.0) due to trace carbon-containing cofactors. When calculated using total carbon input, the carbon-based yield is ~0.98 mol C/mol C.

2. Gut Microbiome GEM
Dynamic Simulation: plot_microbiome.py simulates the 11-species Monod ODE over 100 hours. It strictly normalizes initial 16S abundances (Sum=1) and plots 4 key metrics: Probiotic Abundance, Probiotic/Pathogen Ratio, Shannon Diversity, and Bray-Curtis Distance.
Key Finding (Negative Result): Using unmodified FBA parameters, the model reveals that direct lactate supplementation is largely "hijacked" by commensal/pathogenic bacteria (e.g., Bth, Eco), leading to a lower probiotic abundance. This robustly validates the necessity of our engineering strategy: targeted, in-situ lactate secretion by engineered probiotics rather than oral supplementation.
Figure 4-1: The comprehensive 2×2 comparison plot (All_Metrics_Comparison_vs_Healthy.png) is the core visualization for this module.

3. Tyrosine Pathway
Description: Explores melanin synthesis via TYRTA overexpression and pheA knockout.
Key Findings:
pheA is an essential gene; knockout causes lethality when exogenous Phe/Tyr is limited.
Standard FBA cannot drive non-growth-associated melanin secretion without forced lower bounds (simulating strong promoter induction). By setting EX_melanin_e ≥ 0.1, the model successfully synthesizes melanin with minimal growth burden (~1.1% drop).
Biologically, overexpressing TYRTA (an aminotransferase) tends to consume tyrosine. We recommend using feedback-resistant mutants (e.g., tyrA_fbr) for future wet lab work.

💻 Prerequisites & Dependencies
To reproduce our results, you will need:
MATLAB (R2022a or higher): RAVEN Toolbox 2.11.1, COBRA Toolbox (SteadyCom), Gurobi 13.0.2.
Python (3.8+): pandas, numpy, scipy, matplotlib (Times New Roman used for final figures).
R (4.0+): dada2, phyloseq, vegan (for 16S processing).

📊 Data Sources
16S rRNA Data: NCBI SRA BioProject [PRJNA733204] (Li K et al., 2021).
GEM Models: AGORA 1.0 (Virtual Metabolic Human) for microbiome; iJO1366 (Orth et al., 2011) for E. coli.

This is a FLUKA simulation code and results, intended to support the FLUKA simulation modeling results of LZU-Northwest in the 2026 competition. For specific background, please visit the team's Wiki from that year. The code needs to be opened with the FLUKA software. The results are relatively large, so it is recommended to use a server to view the modeling diagrams and reproduce the results.

The code only includes the neutron source simulation results. For other energy spectra, the same procedure can be followed by replacing the particle source.
