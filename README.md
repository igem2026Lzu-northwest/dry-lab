# iGEM Dry Lab: Space Radiation Intestinal Protection System

Welcome to the Dry Lab repository for our iGEM project!

**Project Title:** A Synthetic Biology-Based Intestinal Protection System for Space Radiation.

## 📖 Project Overview

In deep-space missions and future Mars habitation, astronauts face long-term exposure to space radiation. The intestine is highly radiosensitive, leading to barrier damage, microbiota imbalance, and inflammation. Our project aims to build an engineered probiotic system that secretes **melanin** (to scavenge ROS) and **lactate** (to support epithelial repair and modulate gut microbiota).

This repository contains all the computational models, scripts, and simulation data generated by the Dry Lab team to support this engineering strategy.

## 🧩 Module Architecture

The Dry Lab work is divided into four distinct modules:

1. **FLUKA Simulation (Collaborator)**: Monte Carlo radiation transport modeling to evaluate the physical shielding effect of melanin. *(Not included in this repository).*
2. **Lactate Production (`Lactate_Production`)**: Using genome-scale metabolic models (GEMs, `iJO1366star`) to predict optimal gene knockouts and two-stage fermentation strategies for maximizing lactate yield.
3. **Tyrosine Pathway (`Tyrosine_Pathway`)**: Introducing a melanin synthesis pathway into *E. coli* and exploring metabolic engineering strategies to increase tyrosine supply.
4. **Gut Microbiome GEM (`Gut_Microbiome_GEM`)**: Building an 11-species community model (Monod ODE & SteadyCom) using 16S rRNA data from irradiated mice to predict how lactate regulates the gut microbiota.

🚀 Key Workflows & Scripts
1. Lactate Production
Core Model: iJO1366star extended with a melanin synthesis pathway.

Key Parameters: Glucose uptake = -8 mmol/gDCW/h, ATPM = 8.39, Strict anaerobic.

Core Scripts: We bypassed the standard RAVEN solveLP to avoid dependency issues, directly calling the Gurobi low-level API (gurobi()) for LP solving.

Two-stage Yield: The apparent yield in Stage 2 (2.17 mol/mol glucose) slightly exceeds the theoretical limit (2.0) due to trace carbon cofactors. The carbon-based yield is strictly ~0.98 mol C/mol C.

2. Gut Microbiome GEM
Dynamic Simulation: plot_microbiome.py simulates the 11-species Monod ODE over 100 hours, plotting Probiotic Abundance, Probiotic/Pathogen Ratio, Shannon Diversity, and Bray-Curtis Distance.

Key Finding (Negative Result): The model predicts that direct lactate supplementation is largely "hijacked" by commensal/pathogenic bacteria (e.g., Bth, Eco). This prediction supports, rather than experimentally proves, the rationale for our engineering strategy: targeted, in-situ lactate secretion by engineered probiotics rather than oral supplementation.

Figure 4-1: The comprehensive 2×2 comparison plot (Gut_Microbiome_GEM/07_Figures/All_Metrics_Comparison_vs_Healthy.png) is the core visualization for this module.

3. Tyrosine Pathway
Description: Explores melanin synthesis via TYRTA overexpression and pheA knockout.

Key Findings:

pheA knockout causes lethality when exogenous Phe/Tyr is limited.

Standard FBA requires forced lower bounds (simulating strong promoter induction) to drive melanin secretion.

Biologically, overexpressing TYRTA tends to consume tyrosine. We recommend using feedback-resistant mutants (e.g., tyrA_fbr) for future wet lab work.

📝 Note on Model Iteration and Versioning
The scripts and data provided in this repository represent the final, validated state of our computational workflow.

Parameter Evolution: Initial simulations used default FBA parameters (e.g., glucose uptake -10). Through iterative validation, we refined these (e.g., glucose -8, ATPM 8.39) to reflect realistic batch fermentation limits. The rationale for all final parameters is documented in parameter_provenance_table.csv.

Figure Versions: Early exploratory drafts are omitted for clarity. All figures provided are the final, publication-ready versions generated by the updated Python/MATLAB scripts.

Documented Assumptions: For a detailed discussion on the 2.17 yield discrepancy, the TYRTA directionality, the microbiome "substrate hijacking" phenomenon, and the absence of Veillonella, please refer to model_assumptions_and_limitations.md.

Instead of hiding these iterations, we believe documenting them demonstrates our rigorous Design-Build-Test-Learn (DBTL) process.

💻 Prerequisites & Dependencies
To reproduce our results, you will need:

MATLAB (R2022a or higher): RAVEN Toolbox 2.11.1, COBRA Toolbox (SteadyCom), Gurobi 13.0.2.

Python (3.8+): pandas, numpy, scipy, matplotlib (Times New Roman used for final figures).

R (4.0+): dada2, phyloseq, vegan (for 16S processing).

📊 Data Sources
16S rRNA Data: NCBI SRA BioProject [PRJNA733204] (Li K et al., 2021).

GEM Models: AGORA 1.0 (Virtual Metabolic Human) for microbiome; iJO1366 (Orth et al., 2011) for E. coli.
